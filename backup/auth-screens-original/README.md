# Original NagpurPulse authentication screens backup

These files preserve the original authentication UI source as it existed on `master` before the auth redesign.

- `LoginScreen.kt` — original app path: `app/src/main/java/com/nagpurpulse/ui/screens/auth/LoginScreen.kt`
- `SignupScreen.kt` — original app path: `app/src/main/java/com/nagpurpulse/ui/screens/auth/SignupScreen.kt`

These are backup copies only. The Android app does not reference this folder. To revert the redesign, copy the desired file(s) back to their original app paths.

A separate backup branch, `backup/auth-screens-original-2026-10-04`, is also retained.
